# golden-gate

A Raspberry Pi bridge that puts Wi-Fi and Bluetooth devices onto the home LAN. Each device gets an adapter. The bridge exposes all of them through one web UI and API, so any computer on the home network can use them without joining the device's own network or pairing with it.

First adapter: **Fujifilm Instax SHARE SP-2** (print from any device on home Wi-Fi).

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
